# Research Cycles

Each substantial research question receives a cycle artifact based on `../templates/cycle.md`. The artifact is the narrative audit trail from landscape recon through saturation review: scope, planned source coverage, deep-dive selection, progress, contradictions, checkpoint feedback, and process lessons. Canonical search/source events and a generated source audit accompany it once provenance capture is available.

Use a short topic slug for the filename. Do not create a cycle until its question is bounded enough to guide source selection.
