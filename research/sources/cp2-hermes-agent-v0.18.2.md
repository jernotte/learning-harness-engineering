## Why this source matters

Hermes is the final implementation before the first four-case consolidation. The repository provides direct primary evidence for how the pinned harness connects a user, model, tools, durable state, optional judges, delegated children, memory, and long-horizon artifact maintenance. It is especially useful because it implements more than one completion policy and an active post-turn memory/skill mutation loop, allowing the project to separate runtime integrity, verification evidence, task acceptance, adaptation, and outcome optimization.

The same source also bounds the OpenClaw relationship. It supports separate recorded roots, later migration compatibility, and selected named inspirations or ports. It does not support whole-system fork descent, independent convergence, adoption, effectiveness, or task-success claims.
