# Syntheses

Syntheses compare evidence across systems and sources to answer architectural questions. Organize them around problems and design decisions unless the evidence calls for another structure. Use `../templates/synthesis.md` as a thinking guide.

Only reviewed syntheses should be treated as durable project conclusions. Earlier syntheses are valuable working artifacts, but their status must remain visible.
